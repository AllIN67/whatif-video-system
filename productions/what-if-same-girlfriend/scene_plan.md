## Prüfung vor dem Bau

- [x] Ereignis spätestens bei 10 s (Handys leuchten 6,5 s)
- [x] Alle ≤ 6 s eine sichtbare Zustandsänderung (Validator)
- [x] Monotone Eskalation; jede Zeile bringt Neues (Person → Welt → Planung → Netz → Straße → Privatsphäre → Freunde → Selbstbestimmung → Wendung)
- [x] Ende ≤ 5 s nach der Pointe (4,8 s)
- [x] Blitzregel: keine Weißblenden, Lichtwechsel weich; einzig schneller Wechsel ist das Erlöschen kleiner Lichtpunkte (nicht großflächig)
